# 🌐 My Website – CodVeda Internship Task 1

A simple and responsive multi-page static website developed as part of **Task 1** of my internship at **CodVeda**.

The main goal of this task was to understand the fundamentals of **HTML, CSS, multi-page navigation, and responsive web design**.

---

## 📌 About the Project

**My Website** is a basic static website consisting of three main pages:

- 🏠 Home
- ℹ️ About
- 📩 Contact

The website has a clean and simple design with responsive layouts that work across different screen sizes.

---

## ✨ Features

- Responsive navigation bar
- Multi-page website
- Home page with introduction and services
- About page with project information
- Contact page with contact details and form
- Responsive design using CSS Media Queries
- Clean and simple user interface
- Footer section
- Mobile-friendly layout

---

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and layout
- **CSS Media Queries** – Responsive design
- **Git** – Version control
- **GitHub** – Source code management
- **Render** – Website deployment
