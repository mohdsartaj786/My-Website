ABOUT US

Simple Websites Can Still Be Powerful

MyWebsite is a demonstration of a basic static website created using HTML and CSS. It is designed with a simple structure so that visitors can easily find information.

The website contains multiple pages connected through a common navigation bar. Each page has its own purpose while maintaining the same overall design.

Responsive CSS techniques are used to make the website comfortable to view on desktop, tablet and mobile devices.
